# Family Vibes — R1 Plan

**Prerequisite:** MVP milestone complete and deployed.

> R1 builds on the role model, templates, and platform governance established in the ADRs. None of these items ship before MVP.

---

## R1 scope

### Portal admin (`/portal`)
- Standalone route, accessible only to `isPortalAdmin` users (ADR-002)
- List all families: name, member count, created date, active/suspended status
- Suspend / re-activate a family
- Promote any user to portal admin
- Usage metrics per family: story count, event count, last active date

### Member management (family admin)
- Promote member → admin `{/* [ROLE: family-admin] */}`
- Demote admin → member (cannot demote yourself if last admin)
- Remove a member from the family
- Last-admin guard: block leaving or demotion that would leave a family with zero admins (ADR-006)
- Leave family action for any member (with guard)

### Story & event templates (ADR-007)
- **Phase 1 (R1):** Story templates — admin creates/edits custom templates; member picks one in New Post flow
- Built-in templates (client-side constants): Monthly Update, Event Recap, Member Spotlight
- **Phase 2 (R1 or later):** Event templates
- Template management UI in Family Settings → Templates tab

### Magazine layout config (ADR-007)
- Family Settings → Templates → Magazine Layout tab
- Cover style, font family, colour scheme, section order, include/exclude toggles
- Stored in `family_magazine_config` table (one row per family, upsert)
- Preview: shows a sample cover with selected settings

### Monthly family magazine PDF
- Compiles the month's published stories into a print-ready PDF
- Respects the family's magazine layout config
- Download link generated by an Edge Function (no third-party PDF service in R1 — use Puppeteer or a headless render)
- Accessible to all family members; initiated by any member

### Live event streaming
- Family members post photo/text updates from their phones during an active event
- Updates appear in real time on the event page for all families the event is shared with
- Built on Supabase Realtime subscriptions (no separate WebSocket server)
- Stream updates stored as a new `event_stream` table (not comments — separate feed)

### Event games & polls
- Family admin creates a poll or trivia question attached to an active event
- All members of the event's families can vote / answer in real time
- Results shown live as a bar chart
- Stored in `event_polls` and `event_poll_votes` tables
